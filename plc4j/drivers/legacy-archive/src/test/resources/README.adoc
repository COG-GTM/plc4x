= Legacy archive test fixtures

The binary fixtures in this directory are generated, not hand-written, and are excluded from the
apache-rat license check in this module's `pom.xml` because they can't carry a license header.

Regenerate them with:

[source,shell]
----
mvn -pl plc4j/drivers/legacy-archive -am -P with-java test-compile
mvn -pl plc4j/drivers/legacy-archive -P with-java exec:java \
    -Dexec.classpathScope=test \
    -Dexec.mainClass=org.apache.plc4x.java.legacyarchive.fixtures.FixtureGenerator \
    -Dexec.args=plc4j/drivers/legacy-archive/src/test/resources
----

`exec:java` resolves a relative `exec.args` path against the directory Maven was invoked in, hence
the repository-root-relative path above.

They can also be regenerated by running `FixtureGenerator` (in `src/test/java`) from an IDE with the module's test classpath
and `src/test/resources` as its argument. The generator pins every input — the base timestamp, the
field values and the PDF creation date, producer and title — so repeated runs produce identical
bytes apart from the `/ID` PDFBox derives per save.

== Files

`events.bin`:: Well-formed event log, version 1, six records. Timestamps start at
`2026-03-17T08:00:00Z` and advance one second per record; tag ids are 1, 2, 3, 4, 1, 5; the four
severities info/warn/alarm/fault all occur, and record 3 (tag id 3) has bad quality. Tag id 1
appears twice so the "latest record wins" behaviour of the connection is covered.

`events-bad-magic.bin`:: `events.bin` with the first magic byte replaced by `X`.

`events-bad-version.bin`:: `events.bin` with the version field set to 9.

`events-truncated.bin`:: `events.bin` with the last eight bytes cut off, so the trailing record is
incomplete.

`events-count-mismatch.bin`:: Header announcing six records while only five are present.

`events-bad-reserved.bin`:: Otherwise well-formed log whose records carry a reserved field of 1.

`maintenance-report.pdf`:: One-page report carrying the five labelled lines `Asset ID: PUMP-014`,
`Last Service: 2026-03-17`, `Technician: A. Turing`, `Next Due: 2026-09-17` and
`Hours Run: 18234.5`.

`maintenance-report-empty.pdf`:: One-page report with the heading but none of the labelled fields.

`maintenance-report-blank-asset-id.pdf`:: Same as the valid report, except `Asset ID:` carries no
value.
